# Gavenecko's Prismatic Drift — Mobile Preview

**[Open the mobile test](https://gavenecko.github.io/prismatic-drift-mobile/)**

Version **0.2.0-test1**. A touch-reactive browser prototype, prepared for
testing on phones including the Samsung Galaxy A54.

## Touch controls

- Drag to attract shapes; choose Repel or Off in Settings.
- Tap to release a burst.
- Pinch to zoom and twist with two fingers to rotate.
- Use the bottom toolbar for settings, pause, next preset and fullscreen.

Start with **Balanced** performance. Try Battery saver if the phone gets warm
or complex effects stutter. The full settings are in collapsible sections.
The preset playlist starts only when you choose.

Images and music are selected locally and need reopening each session.
Settings are stored in the browser; use the export option to make a backup.

This is a browser preview, **not an Android APK or live wallpaper**. The
Windows release is a separate build.
